# Sentinel

The downloads of Sentinel, an original arcade game for macOS, Windows and Linux from Reckless Technology: fly a ship
across a wrapping planet, shoot the landers before they carry its people away, and hold back everything that comes
after them, one or two players, wave on wave. Version 1.0 is the first release: high definition at any window size,
drawn on the graphics card, with its own music and stereo sound, and every control yours to change. Free for any use.

| | | |
|---|---|---|
| macOS 13.3 (Ventura) or later, Apple silicon or Intel | [sentinel-macos.pkg](https://github.com/reckless-technology/sentinel-releases/releases/latest/download/sentinel-macos.pkg) | signed and notarized installer |
| Windows 10 or 11, 64-bit | [sentinel-win64-setup.exe](https://github.com/reckless-technology/sentinel-releases/releases/latest/download/sentinel-win64-setup.exe) | signed installer |
| Linux x64: Ubuntu 24.04 or later, and Debian-family systems with glibc 2.38 or later (Debian 13, Mint 22) | [reckless-sentinel-linux-amd64.deb](https://github.com/reckless-technology/sentinel-releases/releases/latest/download/reckless-sentinel-linux-amd64.deb) | `sudo apt install ./reckless-sentinel-linux-amd64.deb` |
| Linux x64, any distribution with glibc 2.38 or later | [sentinel-linux-x64.tar.xz](https://github.com/reckless-technology/sentinel-releases/releases/latest/download/sentinel-linux-x64.tar.xz) | the game, to run from anywhere |

Every release is listed under [Releases](https://github.com/reckless-technology/sentinel-releases/releases) with its
notes and `SHA256SUMS`, each file's checksum. The download page is at
[recklesstechnology.com](https://recklesstechnology.com/plugins/download/#sentinel).

This repository holds the downloads alone. Sentinel is free to use under the end-user licence the macOS and Windows
installers show and every download carries as `EULA.txt`; it is not open source. Questions, bugs and ideas:
hello@recklesstechnology.com.
