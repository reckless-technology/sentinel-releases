# Sentinel

The downloads of Sentinel, an original arcade game for Windows, macOS and Linux from Reckless Technology.

**There is no release yet.** The game is still in development, so there is nothing to download here today. When there
is, every release will be listed under [Releases](https://github.com/reckless-technology/sentinel-releases/releases)
with its notes and `SHA256SUMS`, each file's checksum.

This repository holds the downloads alone. Questions: hello@recklesstechnology.com.
